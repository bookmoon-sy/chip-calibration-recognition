## 一、二值化处理（Otsu、自适应阈值）

### 1. 二值化是什么？作用？

把灰度图按阈值分成两类（前景/背景）。
 作用：**图像分割、目标提取**，便于连通域、形态学、测量（面积/周长/缺陷等）。

### 2. 常见二值化方法（选择题常考）

- **固定阈值**：人为给定 T（简单，但对光照敏感）
- **Otsu（大津）**：自动求全局阈值（适合双峰直方图）
- **自适应阈值**：局部阈值（适合光照不均）

------

### 3. Otsu 法的目的、意义、核心思想（直接可抄）

**目的**：自动选一个全局阈值，使前景和背景分得最开。
 **意义**：不需要手调阈值；当直方图呈明显双峰时分割稳定。
 **核心思想**：遍历所有阈值，使**类间方差最大**（等价于类内方差最小）。

#### Otsu 的关键量（写到卷面很稳）

把像素按阈值 t 分两类：C0(0..t)、C1(t+1..L-1)。

- 类概率（权重）：ω0(t)、ω1(t)
- 类均值：μ0(t)、μ1(t)
- **类间方差**：
   σ_b²(t) = ω0(t) · ω1(t) · ( μ0(t) − μ1(t) )²
   取使 σ_b² 最大的 t 作为最佳阈值。

#### Otsu 步骤（简答题写这几条）

1）统计灰度直方图并归一化为概率
 2）遍历阈值 t
 3）计算两类的权重 ω、均值 μ
 4）计算类间方差 σ_b²(t)
 5）取最大 σ_b² 对应的 t 作为阈值并二值化

**适用条件**：前景/背景灰度差明显、直方图双峰。
 **不适合**：光照不均、目标/背景灰度重叠大（会错分）。

------

### 4. 自适应阈值（Adaptive Threshold）怎么实现？（只写思路）

**思想**：每个像素的阈值不是一个固定值，而是由它周围邻域统计量决定。
 常见两种：

- **局部均值法**：阈值 = 邻域平均值 − C
- **局部高斯加权均值法**：阈值 = 邻域高斯加权平均 − C

关键参数解释（容易出选择题/简答题）：

- 邻域窗口大小（必须奇数）：越大越平滑、越不敏感；太大会丢细节
- 常数 C：用于偏移；C 越大，阈值越高，前景更少（更“严格”）

**适用场景**：光照不均、有阴影、亮度渐变。

------

## 二、图像滤波（去噪）

### 5. 为什么要先滤波？

噪声会造成：

- 二值化阈值不稳定
- 边缘检测出现大量假边缘
- 霍夫检测误检（直线/圆投票乱）

------

### 6. 常用去噪算法（会考“哪个去什么噪声”）

**（1）均值滤波**

- 原理：邻域取平均
- 优点：简单
- 缺点：边缘模糊明显
- 适用：轻度随机噪声

**（2）高斯滤波**

- 原理：高斯核加权平均（中心权重大）
- 优点：抑制高斯噪声好；Canny 前常用
- 缺点：仍会模糊边缘
- 适用：高斯噪声、整体平滑

**（3）中值滤波**

- 原理：邻域排序取中位数
- 优点：对椒盐噪声效果最好，保边性较好
- 缺点：可能损失细小纹理
- 适用：椒盐噪声（黑白点）

------

## 三、边缘检测（Canny、Sobel、自适应阈值思路）

### 7. 边缘是什么？

边缘是灰度变化剧烈的位置。常用梯度表示：梯度越大越可能是边缘。

------

### 8. Sobel 算子（写清楚“做什么 + 输出什么”）

**作用**：计算图像在 x、y 方向的一阶梯度（近似求导），得到边缘强度与方向。
 输出：

- Gx：水平梯度（竖向边缘更明显）
- Gy：垂直梯度（横向边缘更明显）
- 梯度幅值 |G|（边缘强度）
- 梯度方向 θ（边缘方向）

特点：简单快，但对噪声敏感，所以常配合平滑。

------

### 9. Canny 边缘检测（必须把步骤写全）

Canny 是多阶段最优边缘检测框架，完整流程：
 1）**高斯滤波去噪**（抑制噪声假边缘）
 2）**计算梯度幅值和方向**（常用 Sobel）
 3）**非极大值抑制（NMS）**：沿梯度方向只保留局部最大，使边缘变细
 4）**双阈值**：分强边缘和弱边缘
 5）**滞后阈值连接**：弱边缘若与强边缘连通则保留，否则舍弃

#### Canny 双阈值“自适应”怎么理解（考“怎么自适应选阈值”就写这个）

思路：阈值与图像梯度统计相关。常见经验：

- 高阈值 Th 取“较大梯度”的代表值
- 低阈值 Tl 通常取 Th 的 1/2 或 1/3
   即 **Th : Tl ≈ 2~3 : 1**
   核心目的：保证边缘连续，又能抑制噪声边缘。

------

## 四、形态学处理（腐蚀、膨胀、开闭、顶帽黑帽）

### 10. 形态学是什么？解决什么问题？

对二值图（或灰度图）进行“形状/结构”层面的处理，依赖结构元素（核）。
 常用于：**去小噪点、填孔、连通断裂、分离粘连、提取细结构**。

------

### 11. 腐蚀（Erosion）

- 作用：前景缩小，边界向内收
- 效果：去掉小的白噪点；细线可能变断
- 用途：去噪、分离相邻目标

### 12. 膨胀（Dilation）

- 作用：前景扩大，边界向外扩
- 效果：填补小孔、连接断裂
- 用途：连通边缘、填缝

------

### 13. 开运算（Opening）

定义：**先腐蚀后膨胀**。
 作用：去除小白噪点/小毛刺，保持整体轮廓大致不变。
 适用：去小颗粒、去孤立点。

### 14. 闭运算（Closing）

定义：**先膨胀后腐蚀**。
 作用：填小黑洞/小缝隙、连接断裂区域。
 适用：填孔、补断裂边缘。

------

### 15. 顶帽 / 黑帽（公式题常考）

- **顶帽（Top-hat）**：原图 − 开运算(原图)
   含义：提取“小的亮细节”（亮斑、反光点、细小亮结构）
- **黑帽（Black-hat）**：闭运算(原图) − 原图
   含义：提取“小的暗细节”（暗斑、细缝、暗结构）

------

## 五、边缘提取算法总结（选择题常考点）

- **Canny**：综合最好（抗噪、细边、连接性好）
- **Sobel / Prewitt / Roberts**：一阶梯度算子（简单快速）
- **Laplacian**：二阶微分（找零交叉，噪声敏感）
- **LoG**：先高斯再拉普拉斯（比纯 Laplacian 更稳）

------

## 六、线性回归 vs 逻辑回归（实现思路）

### 16. 线性回归（Linear Regression）

任务：预测连续值（回归）。
 模型：y = wᵀx + b
 损失：均方误差 MSE
 训练：用解析解（正规方程）或梯度下降最小化 MSE。
 特点：输出不限制范围。

------

### 17. 逻辑回归（Logistic Regression）

任务：二分类，输出概率。
 模型：p = sigmoid(wᵀx + b)
 sigmoid(z) = 1 / (1 + e^(−z))
 判别：p ≥ 0.5 判为正类（阈值可调）
 损失：对数损失 / 交叉熵
 训练：梯度下降（或牛顿法）最小化交叉熵。
 特点：输出是 0~1 概率，适合二分类。

------

## 七、霍夫变换（直线/圆检测）

### 18. 霍夫变换用来做什么？

从边缘图中检测规则几何形状：**直线、圆**等。
 核心：把“图像空间的点”映射到“参数空间”，用投票找峰值。

------

### 19. 直线霍夫变换（必须会写公式）

直线用极坐标表示：
 ρ = x cosθ + y sinθ
 步骤思路：
 1）先做边缘检测得到边缘点
 2）每个边缘点在参数空间(ρ,θ)投票
 3）累加器中投票峰值对应一条直线
 4）根据(ρ,θ)反算回图像直线位置

为什么用(ρ,θ)：避免斜率形式在垂直线处无穷的问题。

------

### 20. 圆霍夫变换（知道思想即可）

圆参数 (a,b,r)：(x-a)² + (y-b)² = r²
 边缘点对(a,b,r)投票，峰值为圆。

------

## 八、三维视觉与相机模型（F/E/H/P/K、极线约束、畸变）

### 21. 相机投影模型（投影矩阵 P）

3D 点投到 2D 像素：
 s·x = P·X
 其中
 P = K [R | t]
 解释：

- K：内参（相机坐标→像素坐标）
- R,t：外参（世界坐标→相机坐标）
- s：尺度因子

------

### 22. 内参矩阵 K（必背）

K =
 [ fx  0   cx
 0   fy  cy
 0   0   1  ]

含义：

- fx, fy：焦距（像素单位）
- cx, cy：主点坐标
   （有时有 skew，但多数忽略）

------

### 23. 畸变类型（径向 / 切向）与现象

**径向畸变（k1,k2,k3）**：

- 桶形：边缘向外鼓（广角常见）
- 枕形：边缘向内收

**切向畸变（p1,p2）**：
 镜头与成像平面不完全平行、装配偏心导致图像“斜拉”。

考试写法：

- 径向：对称性变形（以中心为轴）
- 切向：非对称偏斜

------

### 24. 基本矩阵 F（Fundamental Matrix）

作用：描述两幅图像像素点之间的**极几何关系**（不需要内参）。
 **极线约束（核心公式）**：
 x'ᵀ F x = 0

含义：

- 给定左图点 x，可在右图确定一条极线 l' = F x
- 右图匹配点 x' 必须落在该极线上
   所以匹配从“2D 搜索”降为“沿一条线 1D 搜索”，减少误匹配。

性质（写一条就行）：F 为 3×3，秩为 2。

------

### 25. 本质矩阵 E（Essential Matrix）

作用：已知相机内参时的极几何关系（使用归一化坐标）。
 关系：E = K'ᵀ F K （同内参时写 Kᵀ F K）
 E 与相机相对位姿(R,t)有关（可用于恢复相机运动）。

------

### 26. H 矩阵（Homography，单应性矩阵）

作用：描述**同一平面**或纯旋转情况下，两幅图的像素映射关系：
 x' ~ H x
 适用：

- 透视矫正（拍斜了拉正）
- 图像拼接（同一平面场景）
- 平面目标配准
   注意点（考试常问）：H 适用于“平面”或“相机纯旋转”；非平面场景一般不能用一个 H 同时对所有点成立。

------

## 九、常见“题目问法”与直接答案句式（抄这个很快）

1）问：Otsu 的目的？
 答：自动选全局阈值，使前景/背景类间方差最大，从而分割效果最好。

2）问：Otsu 的步骤？
 答：统计直方图→遍历阈值→计算两类权重/均值→算类间方差→取最大对应阈值。

3）问：自适应阈值为何适合光照不均？
 答：阈值按局部邻域计算，每个区域用不同阈值，能抵消亮度不均。

4）问：Canny 为什么效果好？
 答：先去噪，再梯度，再非极大值抑制细化边缘，再双阈值+滞后连接保证连续且抗噪。

5）问：开闭运算区别？
 答：开=腐蚀后膨胀（去小白噪点）；闭=膨胀后腐蚀（填小黑洞、连断裂）。

6）问：F 矩阵是什么？
 答：两视图极几何约束矩阵，满足 x'ᵀ F x = 0，对应点在极线上。

7）问：H 矩阵适用条件？
 答：同一平面或纯旋转，满足 x' ~ Hx，用于拼接/透视矫正/配准。

8）问：径向与切向畸变区别？
 答：径向是中心对称的桶形/枕形；切向是装配偏心导致的非对称偏斜。
